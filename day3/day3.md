# Day 3 – Role-Based Prompting

## 60-Day Claude AI Mastery Challenge

### Objective

Learn how assigning a role to Claude improves the quality, relevance, and depth of AI-generated responses.

---

# What is Role-Based Prompting?

Role-Based Prompting is a prompting technique where you tell the AI who it should act as before asking your question.

Instead of asking a general question, you assign an expert role such as:

* Developer
* Product Manager
* HR Manager
* Founder
* Marketer

This gives the AI context about the perspective, knowledge, and communication style it should use.

---

# Experiment 1 – Without Role Prompt

### Prompt

> How can I improve user retention for my mobile app?

### Claude Response (Summary)

* Improve user experience
* Add useful features
* Send notifications
* Collect user feedback

### Observation

The answer was helpful but broad and generic.

---

# Experiment 2 – With Role Prompt

### Prompt

> You are a Senior Growth Product Manager with 10 years of experience in consumer mobile apps.
>
> How can I improve user retention for my mobile app?

### Claude Response (Summary)

Claude suggested:

* Improve first-time onboarding
* Identify activation events
* Track Day-1, Day-7 and Day-30 retention
* Create personalized notifications
* Build habit-forming loops
* Run A/B tests
* Measure retention cohorts

### Observation

The response became more strategic, detailed, and actionable because Claude answered from the perspective of an experienced Growth Product Manager.

---

# Comparison

| Without Role Prompt    | With Role Prompt            |
| ---------------------- | --------------------------- |
| Generic advice         | Expert guidance             |
| Broad suggestions      | Actionable recommendations  |
| Little context         | Role-specific insights      |
| Basic explanation      | Structured framework        |
| Surface-level response | Professional-level response |

---

# Key Learnings

* Assigning a role provides important context before the AI answers.
* Role-Based Prompting produces more relevant and higher-quality responses.
* Claude adapts its tone, structure, and expertise based on the assigned role.
* Different roles generate different perspectives for the same question.
* This technique is valuable for developers, marketers, founders, HR professionals, product managers, and many other domains.

---

# Takeaway

Role-Based Prompting is one of the simplest yet most effective prompt engineering techniques. By clearly defining the role you want Claude to play, you can transform generic answers into expert-level guidance tailored to your specific needs.
