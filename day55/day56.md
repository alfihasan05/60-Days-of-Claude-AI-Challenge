 1. MVP Overview

SmartSave is a focused savings-goal planner designed to help users answer:

> How much should I save, and am I on track?

The MVP allows users to create savings goals, track their progress, understand their saving status, and receive practical guidance.

The Day 6 goal was to bring the core product together into a working MVP while preserving the functionality developed during the previous days.

 2. Features Completed

The MVP includes the following core functionality:

- Create savings goals
- Set goal name, target amount, current savings, and deadline
- Validate user inputs
- Calculate remaining amount
- Calculate required saving pace
- Display progress percentage
- Display savings milestones
- Update current savings
- Show goal status:
  - On Track
  - Behind
  - Completed
- Explain why a goal has its current status
- Provide practical saving suggestions
- Manage multiple savings goals
- Edit existing goals
- Delete goals with confirmation
- Persist goal data using browser local storage
- Handle empty, validation, overdue, and completed states
- Responsive dashboard layout
- Footer credit for the AB Talks challenge
