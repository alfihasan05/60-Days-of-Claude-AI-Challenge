 Day 26 - Prior Authorization Workflow Simulator
Built a single-file interactive Prior Authorization Workflow Simulator to visualize and gamify the US healthcare prior authorization process.

The simulator uses HTML, CSS, and Vanilla JavaScript with no frameworks, CDNs, external dependencies, build tools, or localStorage.

Users move a patient case through three workflow lanes:

Patient -> Provider -> Payer

The application uses drag-and-drop interactions to simulate the complete authorization journey.

 Features

- Patient workflow lane
- Provider workflow lane
- Payer workflow lane
- Drag-and-drop case movement
- Elective surgery scenario
- MRI scenario
- Specialty medication scenario
- Inpatient admission scenario
- Medical necessity evaluation
- Prior authorization document collection
- Submission to payer
- Payer clinical review
- Approval
- Pend
- Denial
- Appeal
- Peer-to-Peer Review
- Workflow progress tracker
- Days elapsed counter
- Efficiency score
- Approval celebration animation
- Completed workflow summary
- Restart functionality
- New Patient functionality
- Responsive design
