 Day 39 — PDF Splitter & Merger

 Project

PDF Splitter & Merger is a browser-based PDF utility for splitting and merging PDF documents through a professional, responsive interface.

All document processing is performed on the client side without requiring a backend service.

 Features

 PDF Splitter

- Upload PDF files
- Drag-and-drop PDF upload
- Automatically detect page count
- Display PDF page thumbnails
- Preview PDF pages
- Split by individual pages
- Create custom page ranges
- Split after specific pages
- Split every N pages
- Extract selected pages
- Create multiple split ranges
- Validate page ranges
- Highlight invalid inputs
- Preview the resulting document structure
- Generate downloadable PDF files

 PDF Merger

- Upload multiple PDF files
- Drag-and-drop uploads
- Display uploaded PDF files
- Show individual page counts
- Preview uploaded documents
- Reorder PDFs before merging
- Display total file count
- Display total page count
- Preview the expected merged structure
- Generate merged PDF
- Download the merged document

 User Interface

The application was designed as a polished commercial PDF utility with:

- Responsive layout
- Dark mode
- Modern typography
- Drag-and-drop interactions
- Loading states
- Processing indicators
- Smooth transitions
- Clear success and error messages
- Keyboard-friendly controls
- Accessible interface elements
- Mobile-friendly design

 Privacy

PDF files are processed locally in the browser.

No documents are uploaded to an external backend during normal application use.

 Technology

- HTML5
- CSS3
- JavaScript
- Client-side PDF processing
- Browser File API
- Drag and Drop API

The application is contained in a single HTML file.
