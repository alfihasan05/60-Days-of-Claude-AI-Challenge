## Objective
Learn how adding context to a prompt significantly improves the quality, relevance, and personalization of AI-generated responses.

# Prompt B (With Context)

# Comparison

| Feature | Prompt A | Prompt B |
|---------|----------|----------|
| Personalization | Generic | Highly Personalized |
| Daily Tasks | General | Goal-Oriented |
| Resources | Generic | Relevant to Claude AI |
| Projects | Basic | Portfolio-Based |
| Motivation | Moderate | High |

## Which roadmap feels more personalized?

Prompt B because it considers the learner's background, available time, learning style, and specific goal.

## Which roadmap would you actually follow?

Prompt B because it provides practical daily tasks, relevant resources, and real projects aligned with the target outcome.

## How did context improve the result?

Adding context helped the AI tailor the roadmap to the learner's needs instead of producing a generic plan. The recommendations became more relevant, actionable, and achievable.

# Key Learnings
- Context helps AI understand the user's goals more accurately.
- Personalized prompts generate more useful and actionable responses.
- Including experience level, available time, and learning preferences improves the quality of the output.
- Context Engineering is one of the most effective Prompt Engineering techniques.
- Better context leads to better AI results.
